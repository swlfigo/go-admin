# Go Admin · 使用文档

面向使用者/运维的操作指南。开发与接口细节见 [`api.md`](./api.md) 与根目录 `README.md`。

## 1. 启动与登录

```bash
# 1) 起 PostgreSQL（Docker）
docker run -d --name go-admin-pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=go_admin -p 5432:5432 postgres:16
# 2) 后端
cd server && make run        # :8080，首次自动建表 + 种子数据
# 3) 前端
cd web && npm install && npm run dev   # :5173
```

浏览器打开 `http://localhost:5173`,默认超级管理员 **`admin` / `admin123`**(验证码默认开启,照图输入)。

## 2. 权限体系怎么用(核心)

Go Admin 是 **RBAC**:`用户 → 角色 → 菜单/按钮权限`。配置全程在后台勾选,无需写代码。

**典型流程(以新增一类"运营"人员为例)**

1. **菜单管理**:确认/新增页面菜单与按钮(每个按钮带权限码,如 `system:user:list`)。
2. **角色管理 → 新增角色**:如"运营专员",填名称/编码。
3. 在该角色行点 **分配权限**:在弹出的**菜单权限树**里勾选它能访问的页面与按钮,保存。
4. **用户管理 → 新增用户**,并在 **角色** 操作里把"运营专员"分配给他。
5. 该用户登录后,**侧栏只显示被授权的菜单**,无权限的按钮也不渲染,后端接口同样拦截。

> 三个预置角色:**超级管理员**(`super_admin`,全权限、不可删)、**伪超级管理员**(`admin`,管用户)、**普通用户**(`user`)。其余角色可自由新建。

## 3. 各模块说明

| 模块 | 能做什么 |
|---|---|
| **工作台** | 登录后首页,展示用户/角色/菜单/在线数等实时统计 |
| **用户管理** | 增删改用户、分配角色、重置密码、解锁、启停用 |
| **角色管理** | 新建/编辑角色、**勾选菜单与按钮权限**(权限树) |
| **菜单管理** | 树形维护目录/菜单/按钮;按钮节点带权限码;编辑可设显示/状态 |
| **字典管理** | 维护下拉枚举(左侧类型 + 右侧数据),运行时可改,无需改代码 |
| **在线用户** | 查看当前在线会话(用户/IP/浏览器/系统/登录时间),可**强制下线** |
| **个人中心** | 改本人资料、修改密码(右上角头像 → 个人中心) |

## 4. 外观 / 主题设置

点右上角**调色板**图标打开「主题设置」抽屉:

- **外观模式**:亮色 / 暗色
- **强调色**:Go 青(默认)、蓝、绿、紫、橙、玫红、青
- **侧边栏**:深色 / 浅色,可设默认收起为图标条
- **标签页样式**:卡片 / 下划线(默认)/ 简约
- **界面密度**:舒适 / 紧凑

设置实时生效并记忆(本地存储)。顶部**标签页**可点击切换、关闭,右键可固定(pin)/批量关闭。

## 5. 配置(运维)

全部集中在 `server/configs/config.yaml`:

```yaml
database:   { host, port, user, password, name, sslmode }   # PostgreSQL 连接
jwt:        { secret, accessMinutes, refreshDays }          # ⚠️ secret 生产必换强随机串
admin:      { username, password }                          # 初始超管(仅首次建库写入)
captcha:    { enabled }                                     # 图形验证码开关
login:      { maxFailCount, lockMinutes, rateLimitPerMinute }  # 防爆破阈值
```

**安全须知**

- 上线前**务必更换** `jwt.secret`(泄露 = 任何人可伪造登录)与 `admin.password`。
- `admin` 账号密码仅在**首次建库**时按 config 写入;之后在「个人中心」改的密码不会被重启覆盖。
- 防爆破已内置:验证码 + 连续失败锁定 + 登录限流 + bcrypt;无需额外配置。

## 6. 常见问题

- **登录后白屏 / 404**:确认后端 `:8080` 在跑、PostgreSQL 已启动。
- **暗色下某组件颜色不对**:主题基于设计 token + Element Plus 变量映射,如发现遗漏可在 `web/src/styles/base.css` 补对应 `--el-*` 变量。
- **"系统"列显示 Intel(Apple 芯片)**:macOS 浏览器 UA 一律上报 `Intel Mac OS X`(防指纹),无法区分架构;已规范化显示为 `macOS`。
- **改了 config 里的 admin 密码不生效**:只对**新建的库**生效;现有库请用个人中心改密,或换新库名重新初始化。
